빌드 설정

?

파일은 언어별 런타임이 필요합니다. 컨테이너 이미지는 VM·OKE·Container Instances에서 실행할 수 있습니다. Function은 별도 패키징 규격을 따릅니다. Functions Maven 실행기는 파일·테스트용입니다. 배포 대상은 빌드 뒤에 선택합니다.

?

선택한 소스를 빌드할 서비스입니다. OCI 저장소는 DevOps를 사용하세요.

?

소스를 컴파일하고 테스트할 도구입니다. Functions 템플릿은 현재 Maven과 JDK 21을 제공합니다.

?

Maven clean 뒤에 실행할 Goal입니다. test는 테스트, package는 패키징, verify는 추가 검증까지 실행합니다.

?

pom.xml의 프로파일을 활성화합니다. 예: quality 또는 ci,quality. Maven의 -P 옵션으로 전달합니다.

?

Git 저장소 안에서 Maven을 실행할 폴더입니다. 루트의 pom.xml을 사용하면 점(.)으로 둡니다.

?

작업 경로 기준으로 저장할 파일 패턴입니다. 예: target/*.jar. 비워도 실행 로그와 생성된 테스트 보고서는 저장합니다.
