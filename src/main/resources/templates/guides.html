처음 사용

상단에서 리전·구획을 선택하세요. 기존 리소스가 있으면 필요한 단계부터 시작합니다.

  1. 소스OCI 저장소를 선택하거나 외부 Git 주소를 등록합니다.소스 등록
  2. 프로젝트·로그DevOps 프로젝트를 선택·생성하고 빌드 로그를 활성화합니다.
    프로젝트저장소·로그 준비
  3. 빌드 설정빌드 명령·환경변수·산출물을 정하고 파이프라인에 연결합니다.
    새 구성기존 파이프라인
  4. 실행·결과작업을 저장한 뒤 실행합니다. 이력에서 상태·로그·보고서를 확인합니다.
    빌드 작업 만들기실행 이력·로그
  5. 배포 · 선택보관된 산출물과 배포 환경을 연결합니다. 새 OKE·Container 구성과 복구는 실험 기능입니다.
    환경 준비배포
시작 전에 확인
  • 소스 URL 등록만으로 OCI의 Git 인증이 설정되지는 않습니다.
  • 테스트만 실행하면 산출물 저장소는 생략할 수 있습니다. 파일·이미지를 보관하려면 전달 단계를 연결하세요.
  • 사용자 조회 권한과 파이프라인 실행 권한은 별도입니다. 권한 설정에서 필요한 작업을 확인하세요.
