OCI에서 구성·권한 확인 ?
Developer Services → DevOps → Projects → 프로젝트 → Deployment pipelines / Artifacts / Environments
CLI: oci devops deploy-pipeline create → deploy-artifact create → deploy-stage create-compute-instance-group-stage
조회에는 프로젝트·배포 환경·Compute·Artifact 읽기 권한, 생성에는 DevOps 파이프라인·배포 Artifact·단계 관리 권한이 필요합니다. 실행 시 DevOps와 VM 에이전트의 서비스 권한도 필요합니다.
