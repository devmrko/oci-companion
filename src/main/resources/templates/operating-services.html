운영 서비스 등록

클러스터 연결과 설정, 해당 NodePort에 적용되는 보안 규칙을 읽어 참조로 저장합니다. Service·보안 규칙·Secret은 변경하지 않습니다.

보관한 보안 규칙 참조

등록 시점의 읽기 전용 스냅샷입니다. 현재 접속 가능 여부는 별도 확인하세요.

앱 상태·Pod 로그

이 서비스에 보관한 구성을 배포 입력 화면으로 불러옵니다. 적용 전 미리보기에서 다시 확인하세요.

최근 실행

최근 시작하거나 조회한 실행 20개입니다. 실행을 열면 빌드·배포의 현재 상태를 조회합니다.

서비스 등록 해제

Companion 등록만 해제합니다. 클라우드 자원과 조회 연결, 실행 이력은 유지되며 진행 중 실행은 취소되지 않습니다.

빌드·push 확인
