신규 설치 · 선택

  3. 관리 화면 인증·TLS와 앱 → 수집기 통신을 설정합니다.

설정 저장됨 · 수집 미확인

배포 환경변수
환경변수 입력용입니다. 기존 JVM 옵션은 유지하세요. 인증 헤더는 Secret에서 주입합니다.


OTLP 추적은 Pinpoint 4.x 기준입니다. Java 활성 요청·스레드 덤프는 Pinpoint 에이전트와 실시간 모듈·Redis 구성을 사용하세요. 두 Java 에이전트를 중복 적용하지 마세요.


  1. 에이전트 설치 후 앱을 다시 배포합니다.
  2. 앱에 요청을 보내고 분석 도구에서 서비스명을 선택합니다.
  3. 최근 요청 시각·응답시간·오류·요청 상세를 확인합니다.
