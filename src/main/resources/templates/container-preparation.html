다음 이미지

OCIR: 공개 이미지는 인증 없이, 사설 이미지는 Container Instances 리소스 주체 IAM으로 다운로드합니다. 아래 Vault Secret은 선택하지 않습니다. 이미지 목록 조회와 다운로드 권한은 별개입니다.


외부 Registry 이미지 · 선택
OCIR 이미지 대신 사용합니다. 위 이미지 선택은 비워 두세요. 태그 대신 digest로 고정합니다.


Secret 내용은 OCI가 읽습니다. 앱은 이름·상태·버전과 OCID만 사용합니다. 비공개 OCIR 이미지는 리소스 주체 IAM을 사용하세요.


Secret 준비·권한 ?
OCI 콘솔 → ID 및 보안 → Vault → Secret. 이미지 계정의 username·password 필드를 가진 JSON을 저장하세요. 현재 구획의 활성 Secret만 표시합니다.
Container Instances 리소스 주체에 해당 Secret의 secret-bundles 읽기 권한이 필요합니다. Secret 교체 후에는 생성값을 다시 확인하세요.

임시 스토리지 기본 15GB: 이미지·로그·쓰기 공간이 공유합니다. 영구 데이터는 외부 저장소를 사용하세요. 사설 OCIR 이미지는 Container Instances 리소스 주체의 읽기 권한과 네트워크 접근이 필요합니다.


HTTP 상태 확인 · 선택
OCI가 15초마다 확인합니다. 실패 시 상태만 표시하며 자동 종료하지 않습니다.


고급 설정 · 선택 ?
명령·인수는 항목별 한 줄입니다. 비워 두면 이미지 기본값을 사용합니다. 환경변수에는 비밀값을 넣지 마세요.




역할·OCI 작업·권한 ?
OCI → Developer Services → Container Instances → Create container instance. 이미지와 CPU·메모리·네트워크를 지정합니다. 기본 임시 저장소 확장·영구 볼륨 연결은 이 도우미에서 제공하지 않습니다.
oci container-instances container-instance list --compartment-id <구획 OCID> --all
oci container-instances container-instance create --from-json file://container-instance.json
oci container-instances container-instance stop --container-instance-id <인스턴스 OCID>
# start / restart / delete도 같은 위치에서 실행합니다.
현재 --profile, --region을 지정하세요. JSON은 이 앱 없이 사용할 수 있습니다.
IAM → Policies에서 관리자가 사용자와 Container Instances의 권한을 설정하세요.
Allow group <그룹> to manage compute-container-family in compartment id <구획 OCID>
Allow group <그룹> to use virtual-network-family in compartment id <구획 OCID>
Allow group <그룹> to read repos in compartment id <구획 OCID>

동적 그룹 일치 규칙:
ALL {resource.type='computecontainerinstance', resource.compartment.id='<구획 OCID>'}

Allow dynamic-group <Container 동적 그룹> to read repos in compartment id <저장소 구획 OCID> where target.repo.name='<저장소 이름>'
필요한 대상 리소스와 작업으로 정책을 좁히세요. OCIR 서비스 게이트웨이 또는 NAT 경로·DNS·보안 규칙도 필요합니다.
