OCI에서 수행 · 권한

트리거: 개발자 서비스 → DevOps → 프로젝트 → Triggers. 수정·삭제·파일 필터도 이곳에서 관리합니다.

oci devops trigger list --project-id <PROJECT_OCID> --all
oci devops trigger create-devops-code-repo-trigger --project-id <PROJECT_OCID> --repository-id <REPOSITORY_OCID> --actions file://actions.json

예약: 거버넌스 및 관리 → Resource Scheduler → Schedules. 시간 변경·삭제는 이곳에서 수행합니다. 목록은 build-pipeline 태그가 현재 파이프라인인 예약만 표시합니다.

oci resource-scheduler schedule list --compartment-id <COMPARTMENT_OCID> --all
oci resource-scheduler schedule create --action START_RESOURCE --compartment-id <COMPARTMENT_OCID> --recurrence-type CRON --recurrence-details '0 0 * * *' --resources file://resources.json

IAM: ID 및 보안 → 정책. 사용자 그룹에는 devops-trigger 관리·devops-family 조회·functions-family 조회·resource-schedule-family 관리 권한이 필요합니다. 실행 서비스의 동적 그룹 권한은 ZIP의 README에 있습니다. 실제 권한 부여는 OCI 콘솔에서 수행하세요.
