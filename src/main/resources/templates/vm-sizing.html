VM 상세새로 조회

변경 확인

볼륨은 축소할 수 없습니다. 백업을 확인하세요. 확장 후 OS에서 디스크 재검색·파일시스템 확장이 필요합니다.

변경된 사양에 따라 비용이 달라집니다. OCI 상태가 바뀌면 적용하지 않습니다.

취소

CPU·메모리

현재 Shape를 유지합니다. 중지된 VM에서 변경하며 자동 시작하지 않습니다.

중지된 VM과 변경 가능한 Flex Shape가 필요합니다. OCI 콘솔에서 상태·지원 여부를 확인하세요.

스토리지 확장

백업·복구

연결된 부트·블록 볼륨의 할당 용량입니다. OS 여유 공간은 포함하지 않습니다.

확장 가능한 연결 볼륨 없음

유형·이름현재 (GB)확장
역할·OCI 작업·권한 ?

Compute → Instances → 인스턴스 → Edit shape. 스토리지: Storage → Block Storage → Boot volumes / Block volumes → Edit size.

oci compute instance update --instance-id <OCID> --shape-config '{"ocpus":2,"memoryInGBs":16}'
oci bv boot-volume update --boot-volume-id <OCID> --size-in-gbs <GB>
oci bv volume update --volume-id <OCID> --size-in-gbs <GB>

CLI에 현재 --profile, --region을 지정하세요. IAM → Policies에서 관리자가 대상 구획의 인스턴스 또는 볼륨 수정 권한을 설정합니다.

Allow group <그룹> to use instances in compartment id <구획 OCID>
Allow group <그룹> to use volumes in compartment id <구획 OCID>

기존 조회 권한도 필요합니다. 할당량·이미지 제약·복제 설정으로 OCI가 변경을 거절할 수 있습니다. 볼륨 복제 활성 상태와 IDE 부트 볼륨은 콘솔에서 먼저 확인하세요.
