OCI에서 확인
파이프라인 추가: DevOps → 프로젝트 → 빌드 파이프라인 → 빌드 파이프라인 생성. 단계 추가: 파이프라인 → 단계 추가 → 관리형 빌드.
oci devops build-pipeline create --project-id <프로젝트 OCID> --display-name <이름>
콘솔 → 개발자 서비스 → DevOps → 프로젝트 → 빌드 파이프라인 → 빌드 실행
CLI: oci devops build-run list --build-pipeline-id <파이프라인 OCID> --all
실행 · arguments.json: {"items":[{"name":"이름","value":"값"}]}
기본값 저장: OCI 콘솔 → 빌드 파이프라인 → 파라미터. 
parameters.json: {"items":[{"name":"이름","defaultValue":"값","description":"설명"}]}
특정 소스 버전: 콘솔 → Start Manual Run → Show advanced options → 저장소·브랜치·커밋. CLI에는 --commit-info file://commit.json을 추가합니다.
commit.json: {"repositoryUrl":"선택 저장소 URL","repositoryBranch":"브랜치","commitHash":"커밋 SHA"}
