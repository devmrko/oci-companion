NodePort 워커 보안 규칙

NodePort Service 점검·생성

한 IPv4 주소(/32)에서 지정한 TCP NodePort로 접근을 허용합니다. 기존 규칙은 보존합니다.

워커 보안 규칙 ·

변경 미리보기

실행 직전 변경 여부를 다시 확인하고 기존 보안 목록을 로컬에 백업합니다.

클러스터 밖 nginx 설정 예시

외부 프록시는 관리자가 설정해야 합니다.

location / {
    proxy_pass http://<워커 주소>:<NodePort>;
    proxy_set_header Host $host;
}
