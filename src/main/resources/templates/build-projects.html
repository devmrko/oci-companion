프로젝트 추가

선택 가능한 알림 주제가 없습니다. 알림 주제 탭에서 생성하세요.

실행 전 프로젝트 로그 활성화와 빌드 리소스의 IAM 권한 설정이 필요합니다.

OCI에서 확인

콘솔 → 개발자 서비스 → DevOps → 프로젝트 → DevOps 프로젝트 생성

oci devops project list --compartment-id <구획 OCID> --all
oci devops project create --compartment-id <구획 OCID> --name <이름> --notification-config file://notification.json

현재 프로파일·리전은 --profile, --region으로 지정합니다.

notification.json: {"topicId":"알림 주제 OCID"}

로그 활성화: DevOps → 프로젝트 → 로그 → 로그 사용. 프로젝트 생성만으로 활성화되지는 않습니다.
