프로젝트 조회·생성
사설 접속

같은 구획·VCN의 IPv4 서브넷. OKE API 접근 경로·보안 규칙·사설 엔드포인트 생성 권한이 필요합니다.

NSG · 선택, 최대 5개
역할·OCI 작업·권한 ?

DevOps → 프로젝트 → Environments → Create environment → Oracle Kubernetes Engine.

oci ce cluster list --compartment-id <구획 OCID> --all
oci ce node-pool list --compartment-id <구획 OCID> --cluster-id <클러스터 OCID> --all
oci devops deploy-environment create-oke-cluster-environment --project-id <프로젝트 OCID> --cluster-id <클러스터 OCID>

CLI에 현재 --profile, --region을 지정하세요. 사설 클러스터는 --network-channel로 접속 서브넷·NSG를 지정합니다.

IAM → Policies에서 관리자가 대상 구획에 정책을 설정합니다.

Allow group <그룹> to read clusters in compartment id <구획 OCID>
Allow group <그룹> to read node-pools in compartment id <구획 OCID>
Allow group <그룹> to read devops-project in compartment id <구획 OCID>
Allow group <그룹> to manage devops-deploy-environment in compartment id <구획 OCID> where request.permission = 'DEVOPS_DEPLOY_ENVIRONMENT_CREATE'

사설 환경은 네트워크 조회 및 Private Endpoint 생성 정책이 추가로 필요합니다. 실제 배포에는 파이프라인 동적 그룹과 클러스터 접근 권한도 필요합니다.
