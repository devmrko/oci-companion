파이프라인 수정

OCI 빌드 단계의 값만 수정합니다. 저장소의 빌드 명령·outputArtifacts와 스크립트 내 Git 주소는 해당 파일에서 변경해야 합니다.

산출물 저장

빌드 → outputArtifacts → Registry 전달. 빌드 사양의 출력 이름과 저장 위치를 연결합니다.

Registry 조회·생성·관리

1. 산출물 저장 위치 등록

DevOps 산출물 참조를 생성합니다. 아직 파일·이미지를 저장하지는 않습니다.

경로·버전을 바꾸려면 새 저장 위치를 등록한 뒤 선택하세요. 다른 출력 연결과 단계 순서는 유지합니다.

2. Registry 전달 단계 추가

뒤에 다른 단계가 없는 빌드 단계에 추가합니다. 기존 연결이 있으면 OCI 콘솔에서 순서를 편집하세요. 외부 Git 빌드 사양을 조회할 수 없는 구성은 콘솔에서 연결하세요.
