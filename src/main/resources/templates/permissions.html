권한 설정 · OCI 콘솔

프로파일의 사용자 그룹에 권한을 부여합니다. 연결 성공만으로 이 메뉴의 권한이 보장되지는 않습니다.

  1. OCI 콘솔 → ID 및 보안 → 도메인 → 해당 도메인 → 사용자에서 프로파일 사용자의 그룹을 확인합니다. 그룹 상세에서 그룹 OCID를 복사합니다.
  2. ID 및 보안 → 정책 → 대상 구획 또는 상위 구획 → 정책 생성 → 수동 편집기 표시.
  3. 필요한 작업의 예제만 선택합니다. <GROUP_OCID>를 실제 그룹 OCID로 바꾸고 대상 구획을 확인합니다.
  4. 정책을 저장하고 전파 후 이 화면에서 다시 조회합니다. 사용자 그룹을 바꿨다면 다시 연결합니다.

정책 생성 권한이 없으면 관리자에게 작업명·프로파일 사용자 OCID·리전·구획·아래 정책 예제를 전달하세요. 앱은 정책을 변경하지 않습니다.



manage 예제는 해당 리소스의 수정·삭제도 허용할 수 있습니다. 필요한 작업만 부여하세요. 다른 구획의 리소스를 사용하면 해당 구획에도 별도 권한이 필요합니다. 루트 구획 선택 시 <COMPARTMENT_OCID>를 작업 대상 구획으로 바꾸세요.


파이프라인 실행 권한

사용자 권한과 별개입니다. ID 및 보안 → 동적 그룹에서 실행 파이프라인을 포함하는 규칙을 만든 뒤 정책을 추가합니다.




ALL {resource.type = 'devopsbuildpipeline', resource.id = '<BUILD_PIPELINE_OCID>'}


아래 각 구획은 실제 리소스가 있는 구획입니다. 소스·산출물 종류에 필요한 항목만 적용합니다.


Allow dynamic-group id <DYNAMIC_GROUP_OCID> to read devops-repository in compartment id <SOURCE_COMPARTMENT_OCID>
Allow dynamic-group id <DYNAMIC_GROUP_OCID> to read devops-deploy-artifact in compartment id <PROJECT_COMPARTMENT_OCID>
Allow dynamic-group id <DYNAMIC_GROUP_OCID> to use ons-topics in compartment id <TOPIC_COMPARTMENT_OCID>
Allow dynamic-group id <DYNAMIC_GROUP_OCID> to read artifact-repositories in compartment id <REGISTRY_COMPARTMENT_OCID>
Allow dynamic-group id <DYNAMIC_GROUP_OCID> to manage generic-artifacts in compartment id <REGISTRY_COMPARTMENT_OCID>
Allow dynamic-group id <DYNAMIC_GROUP_OCID> to manage repos in compartment id <REGISTRY_COMPARTMENT_OCID>
Allow dynamic-group id <DYNAMIC_GROUP_OCID> to read secret-family in compartment id <VAULT_COMPARTMENT_OCID>


구독 없이 주제만 생성해도 수신자는 없습니다. 로그는 DevOps → 프로젝트 → 로그에서 별도로 활성화합니다.




401: 프로파일·API 키 확인. 403/404: 권한뿐 아니라 리전·구획·리소스 존재 여부도 확인합니다. 조회 실패를 권한 부족으로 단정하지 않습니다.
