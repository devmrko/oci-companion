ARM 이미지 빌드

등록한 ARM VM에서 OCI 저장소의 고정 커밋을 테스트하고 이미지로 빌드합니다.

OCI Managed Build 지원 점검

현재 연결된 SDK가 제공하는 이미지 목록입니다. 새로 조회하면 목록을 다시 확인합니다. 전체 OCI 서비스의 미공개 옵션을 조회하는 기능은 아닙니다.

다시 점검 · OCI Managed Build 공식 안내

buildx·QEMU 교차 빌드는 별도 대안입니다. 느릴 수 있고 실제 ARM 노드에서 추가 검증이 필요합니다. 이 경로에서는 자동으로 사용하지 않습니다.

ARM VM 등록

등록한 VM에 podman·bash·tar가 있어야 합니다. SSH 호스트 키 검증은 유지합니다. 빌드 시 CPU 아키텍처를 확인합니다.

명령은 선택한 VM에서 소스 디렉터리를 기준으로 실행합니다. 비밀값을 명령에 넣지 마세요.

실행 미리보기

소스 전달 → ARM 확인 → 테스트 → podman build --platform linux/arm64 → OCIR push → digest 확인
이번 실행의 OCIR 로그인 · 선택
입력하지 않으면 VM의 기존 podman 인증을 사용합니다. 입력한 토큰은 설정·실행 기록에 저장하지 않습니다.
