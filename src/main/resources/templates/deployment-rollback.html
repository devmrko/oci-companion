이전 배포 복구

실험 기능 전용 검증 환경에서 먼저 실행하세요.

복구 대상 확인

OCI에 저장된 이 실행의 단계 스냅샷으로 다시 배포합니다. 현재 파이프라인 설정과 다를 수 있습니다. 서비스 중단이 발생할 수 있으며 DB·영구 저장소 데이터는 복구하지 않습니다.

취소
OCI 작업·권한 ?

DevOps → 프로젝트 → Deployment Pipelines → Deployments → 단계 메뉴 → Manual Rollback. 현재 프로파일의 배포 실행 권한과 배포 대상 접근 권한이 필요합니다.

oci devops deployment create-single-stage-redeployment --help
