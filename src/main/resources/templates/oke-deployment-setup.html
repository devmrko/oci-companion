Developer Services → DevOps → 프로젝트 → Deployment Pipelines에서 OKE 단계를 구성합니다. 명세는 표준 Kubernetes YAML이며 앱 없이 적용할 수 있습니다.
oci devops deploy-stage create-deploy-oke-stage --help
kubectl apply --dry-run=server -f deployment.yaml
kubectl apply -f deployment.yaml
사용자에게 프로젝트·배포 파이프라인·아티팩트·단계 관리와 이미지 읽기 권한이 필요합니다. DevOps의 클러스터 접근 권한, 노드의 OCIR 읽기 권한은 별도로 필요합니다. 관리자에게 IAM → Policies에서 필요한 프로젝트·구획 범위로 설정하도록 요청하세요.
Service는 ClusterIP입니다. 외부 공개는 기존 Ingress·Load Balancer 구성을 연결하세요. CPU·메모리는 Pod 설정이며 노드 사양을 변경하지 않습니다.
