인증·권한 ?
OCI 프로파일은 Vault 읽기에 사용합니다. Gitea는 서버에 등록한 env:GITEA와 Gitea 사용자명을 사용할 수 있습니다. GitHub는 x-access-token, GitLab은 oauth2, OCI는 tenancy/[domain/]username을 입력하세요. 토큰에는 대상 저장소 쓰기 권한이 필요합니다. 보호 브랜치는 별도 브랜치에서 작업하세요.
OCI 콘솔 → 보안 → Vault → Secret에 토큰 저장. 관리자에게 해당 Secret의 read secret-bundles 권한을 요청하세요. OCI Git Auth Token은 내 프로파일 → Auth tokens에서 생성합니다.
