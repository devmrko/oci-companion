백업·복구 · OCI 작업·권한

Storage → Block Storage → Block Volumes → Backups → Create backup. 복원은 Block Volume Backups → Restore Block Volume. 정기 정책은 Backup Policies에서 설정합니다.

oci bv backup create --volume-id <볼륨 OCID> --type INCREMENTAL
oci bv backup list --compartment-id <구획 OCID> --all
oci bv volume create --availability-domain <AD> --compartment-id <구획 OCID> --source-details '{"type":"volumeBackup","id":"<백업 OCID>"}'

CLI에 현재 --profile, --region을 지정하세요. IAM → Policies에서 관리자가 대상 구획의 볼륨·백업 권한을 설정합니다. 조회만 필요하면 read, 생성·복원은 아래 권한에서 필요한 작업만 허용하세요.

Allow group <그룹> to manage volume-backups in compartment id <구획 OCID>
Allow group <그룹> to manage volumes in compartment id <구획 OCID>

키로 암호화한 백업은 키 접근 권한도 필요합니다. 만료 시각은 자동 삭제 예정 시각, 보존 기간 종료는 보호 기간의 종료 시각입니다. 법적 보존·보존 잠금 등 보호 설정도 함께 확인하세요. 백업 삭제·보호 설정 변경은 OCI 콘솔에서 수행하세요. 앱은 IAM 정책을 변경하지 않습니다.

정기 백업 정책 · OCI 작업·권한

앱을 종료해도 OCI가 예약 백업을 실행합니다. 실행 결과는 백업·복구 탭에서 조회하세요. 애플리케이션·DB 일관성 확보는 별도 절차가 필요합니다.

Storage → Block Storage → Block Volumes → 볼륨 → Backup Policy → Assign / Edit / Remove. 정책 작성은 Backup Policies → Create Backup Policy.

oci bv volume-backup-policy list --all
oci bv volume-backup-policy list --compartment-id <구획 OCID> --all
oci bv volume-backup-policy-assignment get-volume-backup-policy-asset-assignment --asset-id <볼륨 OCID>
oci bv volume-backup-policy-assignment create --asset-id <볼륨 OCID> --policy-id <정책 OCID>
oci bv volume-backup-policy-assignment delete --policy-assignment-id <연결 OCID>

CLI에는 현재 --profile, --region을 지정하세요. 권한이 없으면 관리자에게 OCI 콘솔 → Identity & Security → Policies에서 대상 구획 권한을 요청하세요.

Allow group <그룹> to inspect volumes in compartment id <구획 OCID>
Allow group <그룹> to inspect backup-policies in compartment id <구획 OCID>
Allow group <그룹> to manage backup-policy-assignments in compartment id <구획 OCID>

조회만 필요하면 연결 권한을 inspect로 제한하세요. 실행 직전에 상태를 다시 확인합니다. OCI 연결 API에는 조건부 교체 기능이 없으므로 같은 볼륨을 동시에 수정하지 마세요.
