주제 생성 → 프로젝트에 연결 → 구독 등록. 이메일 구독은 수신자의 확인 후 활성화됩니다.

알림 주제 생성

상단에서 선택한 리전·구획에 생성합니다. 구독은 자동 생성하지 않습니다.

OCI에서 확인

주제 생성: 콘솔 → 개발자 서비스 → Application Integration → Notifications → 주제 → 주제 생성



구독 등록: 주제 선택 → 구독 → 구독 생성 → 프로토콜·수신 대상 입력


현재 앱에서는 구독을 등록하지 않습니다. 이메일은 확인 메일의 링크를 눌러야 수신됩니다.


로그 활성화: DevOps → 프로젝트 → 로그 → 로그 사용


사용자에게 주제 조회·생성 권한이 필요합니다. DevOps 리소스의 주제 사용 권한은 별도 IAM 정책으로 설정합니다.
