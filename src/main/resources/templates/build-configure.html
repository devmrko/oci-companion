1. 소스

앱 소스와 build_spec.yaml을 같은 저장소에 두면 선택한 커밋이 함께 적용됩니다.

기존 소스 선택·등록 ↗
외부 연결 ?

URL 등록은 소스 목록 저장입니다. OCI에서 GitHub·GitLab을 읽으려면 프로젝트의 외부 연결과 Vault 인증 참조가 필요합니다. OCI 콘솔 → DevOps → 프로젝트 → 외부 연결.

3. 파이프라인

프로젝트 선택 → 파이프라인 생성 → 빌드 단계 추가

프로젝트 선택·생성 ↗파이프라인·빌드 단계 ↗
프로젝트·파이프라인 ?

프로젝트는 소스·권한·로그를 묶는 단위입니다. 파이프라인은 빌드·저장 등 실행 순서를 담습니다. 빌드 단계에서 소스·명세 경로·실행 이미지를 지정합니다.

4. 산출물

테스트만: 출력·전달 단계 생략. 파일·이미지 저장: 출력 이름 → Registry 참조 → 전달 단계 연결.

Registry 선택·생성 ↗산출물 전달 설정 ↗
출력과 저장소 ?

명세의 출력은 빌드 환경에서 만들어진 파일·이미지입니다. 전달 단계를 연결해야 Registry에 보관됩니다. 보고서는 명세의 Object Storage 보관 또는 Registry 전달을 선택합니다.
