역할·OCI 작업·권한 ?
배포 환경은 배포할 VM의 참조입니다. 기존 환경을 재사용할 수 있고, 환경이 없어도 빌드는 가능합니다.
콘솔: DevOps → 프로젝트 → 환경 → 환경 생성 → Instance Group. VM 조건: Compute → 인스턴스 → Oracle Cloud Agent → Compute Instance Run Command.
프로파일의 그룹에는 대상 구획의 인스턴스·이미지 조회 및 devops-deploy-environment 조회 권한이 필요합니다. 환경 생성은 해당 리소스의 생성 권한도 필요합니다. IAM → 정책에서 관리자가 설정하세요.
Allow group <그룹> to read instances in compartment id <구획 OCID>
Allow group <그룹> to read instance-images in compartment id <구획 OCID>
Allow group <그룹> to read devops-project in compartment id <구획 OCID>
Allow group <그룹> to read devops-deploy-environment in compartment id <구획 OCID>
Allow group <그룹> to manage devops-deploy-environment in compartment id <구획 OCID> where request.permission = 'DEVOPS_DEPLOY_ENVIRONMENT_CREATE'

oci compute instance list --compartment-id <구획 OCID> --all
oci devops deploy-environment list --compartment-id <구획 OCID> --all
oci devops deploy-environment create-compute-instance-environment --project-id <프로젝트 OCID> --compute-instance-group-selectors file://selectors.json
CLI에는 현재 --profile, --region을 지정하세요. 위 정책은 사용자 조회·환경 관리용이며 실제 배포 서비스 권한과 다릅니다.
