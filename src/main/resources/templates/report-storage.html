버킷 생성

현재 리전·구획에 Standard 버킷을 생성합니다. 보존 기간은 OCI 수명 주기 정책에서 설정하세요.

Object Storage · 권한 ?

OCI 콘솔 → 스토리지 → Object Storage → 버킷. 사용자: 버킷 조회·생성, 객체 조회 권한. 빌드 파이프라인: 대상 버킷의 객체 생성·덮어쓰기 권한이 필요합니다.

OCI 콘솔 → ID 및 보안 → 정책에서 관리자가 적용합니다. 동적 그룹에는 해당 DevOps 빌드 파이프라인을 지정하세요.

Allow group <사용자 그룹> to read buckets in compartment <구획>
Allow group <사용자 그룹> to manage buckets in compartment <구획> where request.permission = 'BUCKET_CREATE'
Allow group <사용자 그룹> to read objects in compartment <구획> where target.bucket.name = '<버킷>'
Allow dynamic-group <빌드 동적 그룹> to manage objects in compartment <구획> where all {target.bucket.name = '<버킷>', any {request.permission = 'OBJECT_CREATE', request.permission = 'OBJECT_OVERWRITE'}}
oci os bucket list --profile '<프로파일>' --region '<리전>' --compartment-id '<구획 OCID>' --all
