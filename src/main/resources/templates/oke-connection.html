OKE 조회 연결

등록 앱 상태

현재 OCI 프로파일을 사용합니다. 사설 엔드포인트는 이 앱 서버에서 해당 네트워크에 접근할 수 있어야 합니다.

배포 앱 목록

Deployment·ReplicaSet·Pod 조회를 확인한 뒤 로컬에 저장합니다. 클러스터와 앱은 변경하지 않습니다.

접속 준비·권한 ?

Companion 서버에 OCI CLI와 kubectl이 필요합니다. OCI 콘솔 → 개발자 서비스 → Kubernetes 클러스터 → 클러스터 액세스에서 접속 방법을 확인할 수 있습니다.

OCI 클러스터 조회·접근 권한과 Kubernetes RBAC를 확인하세요. namespace 목록은 namespaces list, 배포 앱 선택은 deployments list, 상태 조회는 deployments get·replicasets/pods list 권한을 사용합니다. namespace 목록 권한이 없으면 이름을 직접 입력하세요.

경고 이벤트 조회에는 해당 namespace의 events list 권한이 필요합니다. 권한이 없으면 이벤트 영역만 조회 불가로 표시합니다.

할당 노드 조회는 선택 사항이며 클러스터 범위 nodes get 권한이 필요합니다. 노드 조회 실패는 Pod 결과와 별도로 표시됩니다. 이 화면은 IAM·RBAC를 변경하지 않습니다.

OCI 네이티브 kubeconfig의 서버 주소·CA를 사용하며, 토큰 생성에는 현재 프로파일을 고정합니다. 기존 ~/.kube/config는 변경하지 않습니다. HTTP health와 로그·알림은 별도 연동입니다.
