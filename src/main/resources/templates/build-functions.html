빌드 실행실행 이력

Fn Project 템플릿

func.yaml · Dockerfile · 실행 코드 · 요청 예제 · OCI/Fn CLI 구성 안내. 다운로드로 OCI 리소스가 생성되지는 않습니다.

구성 순서
  1. 애플리케이션·서브넷·결과 버킷 확인 또는 생성
  2. 빌더 이미지 생성 → Container Registry 업로드 → Function 배포
  3. 결과 버킷 쓰기 권한·로그 설정
  4. 이 화면에서 다시 조회 → 빌드 실행

템플릿은 앱 없이 사용할 수 있습니다. 빌더 이미지 준비와 사용자 소스 빌드는 별도 단계입니다.

공개 GitHub·GitLab 저장소
?

이번에 빌드할 소스 버전입니다. Git 커밋의 40자리 SHA를 입력합니다.

?

Maven clean 뒤에 실행합니다. test는 테스트, package는 패키징, verify는 추가 검증까지 실행합니다.

?

pom.xml의 프로파일을 활성화합니다. 예: quality 또는 ci,quality. -P 옵션으로 전달합니다.

?

저장소 안에서 Maven을 실행할 폴더입니다. 루트의 pom.xml을 사용하면 점(.)으로 둡니다.

?

작업 경로 기준 파일 패턴입니다. 예: target/*.jar. 비워도 로그와 생성된 보고서는 저장합니다.

테스트만 실행하면 비워두세요.

결과는 선택한 Function의 버킷에 저장됩니다. 접수 후 실행 이력에서 확인하세요.
