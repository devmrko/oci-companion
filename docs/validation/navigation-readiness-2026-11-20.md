# 메뉴·준비 상태 검증

검증일: 2026-11-20. 실제 OCI DEFAULT 프로파일, 서울 리전의 선택 구획 사용. 신규 빌드·배포·IAM 변경 없음.

## 변경

- 메뉴: 개요 / 소스 / 빌드 / 산출물 / 배포 / 환경·운영 / 설정의 2단계 구조.
- 공통 용어 도움말: 쉬운 이름, OCI 명칭, 콘솔 위치, CLI 예시.
- 공통 배지: 필수 / 조건부 필수 / 선택. 기존 입력 검증 유지.
- 공통 상태: 충족(초록), 확인 필요(노랑), 조치 필요(빨강), 미확인(회색), 해당 없음.
- 준비 상태와 실행 결과를 분리. 조회 성공으로 실행 권한을 추정하지 않음.
- 테스트 상태는 선택한 보고서에 한정. 선택 변경·조회 실패 시 미확인으로 복귀.

## 검증 결과

| 항목 | 결과 |
|---|---|
| Java 테스트 | 271개 통과, 실패·건너뜀 없음 |
| 보고서 상태 JS | 통과·실패·PMD 경고·보고서 없음·선택 변경·오류·전체 제외 검증 |
| 실제 Maven 파이프라인 | 필수 충족 4/5, 미확인 1. 실행 권한·로그는 미확인 |
| 실제 Python 보고서 | 테스트 2개 조회 후 초록, 다른 산출물 선택 시 회색 |
| 실제 전달 실패 실행 | 빌드 초록, 산출물 저장 빨강으로 구분 |
| 배포 대상 조회 실패 | 준비 상태 회색. 실행 가능으로 표시하지 않음 |
| 메뉴 | 실행 이력·컨테이너 이미지·알림의 단일 활성 메뉴 확인 |
| 도움말 | OCI 명칭·콘솔·CLI 표시, Escape 닫기·포커스 복귀 확인 |
| 모바일 390px | 가로 넘침 없음, 메뉴 열기·Escape 닫기 확인 |
