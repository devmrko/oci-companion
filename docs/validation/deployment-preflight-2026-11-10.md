# 배포 전 점검 표시

2026-11-10. 기존 OCI SDK의 배포 미리보기 검증 결과를 점검표로 표시합니다. 별도 상태 저장소나 IAM 변경은 추가하지 않았습니다.

- 확인: 파이프라인 ACTIVE, 선택 구획, VM RUNNING 또는 OKE 환경·클러스터 ACTIVE. VM 인라인 명세·산출물 참조 형식, OKE 지원 명세·Namespace·digest 지정.
- 빌드를 선택한 경우: 전달 파일 SHA-256·크기 일치. 빌드를 선택하지 않은 일반 배포는 ‘선택 없음’으로 표시합니다.
- 미확인: 실행 주체 IAM, 이미지 인증·아키텍처, 네트워크·앱 응답. VM은 에이전트·런타임·디스크 준비도 미확인입니다. 확인 위치·방법을 함께 표시합니다.
- 조회·검증 오류: 실행 불가 사유와 미확인 항목 표시. 기존 실행 티켓·실행 직전 재검증을 유지합니다.

확인 표시가 이미지 존재·pull 성공·Kubernetes 내부 상태 또는 앱 정상 응답을 뜻하지 않습니다. 이 구현은 기존 검증을 보여주는 첫 단계이며 네트워크 연결 시험이나 노드 아키텍처 자동 대조 기능은 추가하지 않았습니다.

실제 DEFAULT / ap-seoul-1 / Joungmin.Ko 환경에서 브라우저 검증:

1. 기존 OKE 파이프라인 미리보기: 확인 2항목, 권한·이미지·네트워크 미확인, 실행 버튼 표시.
2. 중지 VM 대상: 실행 불가, 확인으로 표시된 항목 없음, 실행 버튼 없음.
3. 실행 이력 화면: 현재 배포 전 점검표가 표시되지 않음.
4. 390/768/1440px 가로 넘침 없음. 상태 셀은 공통 CSS `table-cell--status`로 줄바꿈 방지.

Java 220개 통과. 실제 화면은 `scripts/browser-deployment-preflight.cjs`로 검증합니다. 로컬 근거: `.tools/deployment-preflight-{390,768,1440}.png`, `.tools/deployment-preflight-blocked.png`. 새 배포·VM 시작·IAM 변경 없이 기존 OCI 리소스를 조회했습니다.
