# 화면 흐름 연결 검증

2026-11-20. 기존 Foundation MVC·상태 컴포넌트를 재사용했다. 새 의존성 없음.

## 수정

- 등록 소스 → 해당 소스를 선택한 빌드 구성. 다른 구획의 OCI 소스는 구획 선택 안내.
- 준비 상태 → 소스·명세·단계·산출물 연결의 해당 위치로 이동.
- 공통 파이프라인 메뉴 → 준비 상태 재조회 / 실행 설정 / 이력·보고서. 선택 ID 유지.
- 산출물 저장 흐름 → 저장소 목록 대신 출력·전달 연결 설정.
- 성공 빌드의 배포 상태 링크 → 선택 파이프라인·실행 ID 전달. 배포 준비에서 원래 빌드·보고서로 복귀.

## 확인

- Java 테스트 272개 통과. 성공 실행 ID 인코딩·전달과 실패 실행 제외 검증 포함.
- Orca 브라우저, DEFAULT / 서울 / 선택 구획, 격리 서버 8092.
- 실제 db-companion Git 주소를 격리 로컬 소스 목록에 등록. 빌드 구성의 소스·브랜치 및 다음 파이프라인 링크 유지 확인.
- 실제 Maven 파이프라인의 명세 링크 클릭: 접힌 입력 폼 열림, 화면 이동, 준비 상태 복귀 URL 확인.
- 실제 Python 성공 실행의 배포 링크 클릭: sourcePipeline/sourceRun 및 복귀 링크 일치 확인.
