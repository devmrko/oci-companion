# alpha.10 설치·업데이트 검증

2026-11-10. Codex가 릴리스 ZIP을 독립 폴더에서 실행하고 실제 DEFAULT 프로파일의 OCI 자원으로 화면을 검증했습니다.

- Java 테스트 259개 통과.
- 빈 데이터 설치: 백업·정책·빌드 설정·명세·등록 앱·소스·빌드·배포 이력·OKE 구성·Container Instances 10개 화면. HTTP 200, JavaScript 오류 없음, 390·768·1440px 가로 넘침 없음.
- 실제 프로젝트·알림·Registry 목록과 생성 폼을 3개 너비에서 확인.
- 새 공유 OKE 권한 도움말을 실제 임시 계정의 연결·로그 2개 화면에서 3개 너비로 확인.
- alpha.9 설치의 데이터 복사본에서 JAR만 교체. 설정 JSON 319개 해시 유지. 소스 목록·리전·구획·등록 앱 유지. 기존 OKE 연결의 준비 완료와 namespace·Deployment 값 유지.

패키지 검증에서 빌드·배포를 재실행하지는 않았습니다. 이번 실제 실행 근거는 [Container Instances 사설 이미지](container-pull-policy-2026-11-10.md)와 [OKE RBAC](oke-rbac-2026-11-10.md)입니다. 외부 신규 사용자가 수행한 검증은 아닙니다. 사설 API 성공은 미검증으로 남습니다.

실행한 JAR와 최종 ZIP JAR의 SHA-256을 비교합니다. 배포본에는 JAR·실행 스크립트·안내·검증 문서만 넣습니다. 업데이트는 같은 설치 경로에서 수행하며 `.data`·`.tools`와 별도 지정 설정을 보존합니다.
