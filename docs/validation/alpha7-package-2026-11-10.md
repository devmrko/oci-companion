# alpha.7 설치·업데이트 검증

2026-11-10. 최근 배포 점검·이미지 아키텍처 수정을 설치 ZIP에 포함했습니다.

## 새 설치

- 최종 소스 Java 테스트 230개 통과 후 ZIP 생성.
- ZIP의 JAR SHA-256이 테스트한 JAR과 일치함을 확인.
- ZIP에 `.env`, `.data`, `.oci`, `.git` 경로가 없음을 확인.
- 별도 폴더에 압축 해제, 빈 데이터로 8092 실행. 개발 환경의 `.env`를 로드하지 않았습니다. 기존 OCI API 키 프로파일만 사용했습니다.
- DEFAULT / ap-seoul-1 / Joungmin.Ko로 연결, 실제 OCI 주요 화면 10개 HTTP 200 확인.
- 독립 ZIP에서 사설 OCIR 이미지의 linux/amd64와 명세 amd64 일치 표시, 실행 버튼 확인. 새 배포는 실행하지 않았습니다.
- 390/768/1440px 페이지 가로 넘침 없음, 브라우저 JavaScript 오류 없음.

## 업데이트

기존 alpha.6 독립 검증 폴더의 `.data`를 별도의 alpha.7 폴더에 복사했습니다. 원본 데이터는 수정하지 않았습니다. 프로파일 연결 후 저장된 리전·구획과 등록 소스 이름이 유지되는지 실제 화면에서 확인했습니다. 주요 화면 10개도 다시 확인했습니다. 모든 사용자 데이터 유형이나 과거 모든 버전의 마이그레이션을 검증한 것은 아닙니다.

검증 후 소유한 8092 서버를 종료했습니다. 8091 개발 실행본과 OCI 리소스는 변경하지 않았습니다. OCI 조회·로컬 범위 설정 외에 빌드·배포·IAM 변경은 하지 않았습니다.

화면: 백업 이력, 백업 정책, 빌드 설정, 빌드 명세, 에이전트 연결, 소스, 빌드, 배포 실행, OKE 구성, Container Instances 준비.

로컬 증거: `.tools/alpha7-build.log`, `.tools/alpha7-smoke.json/png`, `.tools/alpha7-architecture-match.png`, `.tools/alpha7-upgrade.json/png`. 개인 데이터와 인증 관련 로그는 배포 ZIP에 포함하지 않습니다.

이번 검증은 기존 OCI 환경의 설치·업데이트·조회 검증입니다. 새 테넌시에서 소스·빌드·배포 자원을 모두 만드는 신규 사용자 전체 흐름이나 실제 OKE 노드 스케줄링 검증을 대신하지 않습니다.
