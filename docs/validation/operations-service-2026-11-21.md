# 배포 서비스 공통화 검증

2026-11-21 KST. 일반 배포 실행 화면을 `DeploymentOperations`로 연결했다. 조회·판단·계획 발급·실행이 HTTP 세션 객체 없이 동작한다. 인증된 주체와 interaction은 호출 어댑터가 전달한다.

- Java 테스트 287개 통과. 임의 계획 ID, 만료, 다른 구획·interaction, 변경된 명세, 차단 이미지, 재사용을 검사했다. 기존 CSRF·빌드 일치·이미지·아키텍처 웹 테스트도 통과했다.
- 실제 DEFAULT / 서울 프로파일로 브라우저에서 이미지 일치 계획 발급과 불일치 실행 차단을 확인했다.
- 실제 OKE 환경·OCIR 이미지 조회 후 ConfigMap·Secret·ServiceAccount 참조, startup/liveness, 종료 대기 60초를 입력하고 미리보기 YAML 반영을 확인했다.
- 이번에는 배포 구성을 저장하거나 새 배포를 실행하지 않았다. 참조 이름은 미리보기 검증값이며 존재·권한·Pod 동작을 검증한 값이 아니다.
- 실제 LLM/MCP 호출은 아직 없다. 서비스의 비HTTP 호출은 단위 테스트로 검증했다. 기존 실제 빌드→OKE 결과는 별도 11월 21일 검증 문서에 있다.
