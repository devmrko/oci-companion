# 빌드 실행 요약·비교 — 2026-11-20

DevPrism 소개서의 단계별 병목·기간 비교·품질 근거 연결을 참고해 OCI DevOps 빌드 이력에 실행 요약·비교를 추가했다. 소개서의 가상 시안 데이터를 사용하지 않았다.

## 구현

- 빌드 → 실행 이력 → 실행 요약·비교. 실행 상세에서도 이전 실행과 비교한다.
- 현재 프로파일·리전·구획·파이프라인의 최근 7/28/90일 실행 수, 성공·실패·취소·기타, 실행 시간 중앙값.
- OCI BuildRunProgressSummary 및 단계·하위 작업의 시작/종료 시각을 사용한다. timeUpdated를 종료 시각으로 대체하지 않는다.
- 대기 시간, 실행 시간, 요청 커밋·저장소·브랜치, 실행 당시 Shape·이미지·명세 경로 비교. 단계 클릭은 실행 로그의 상위 단계 필터로 연결한다.
- 두 실행의 Generic Artifact tar.gz 산출물을 선택해 기존 JUnit·PMD 판독기로 보고서를 조회한다. 파일이 하나일 때만 자동 선택한다.
- 기존 BuildHistory 인터페이스·OCI 어댑터·TestReports·범위 검증·공통 CSS를 확장했다. 새 저장소·DB·의존성은 추가하지 않았다. Foundation의 기존 MVC·오류 기반을 유지하며 OCI 전용 집계는 프로젝트에 둔다.

- db-companion-maven: 최근 28일 10건, 성공 6·실패 4, 중앙값 5분 5초. 최근 두 실행에서 빌드 단계는 성공했으나 산출물 전달 상태가 SUCCEEDED/FAILED로 다른 것을 확인했다.
- Python HTTP API 파이프라인: 실제 두 실행의 test-reports 산출물을 선택해 각각 테스트 2·실패 0·오류 0·제외 0을 확인했다. PMD 기록은 없었다.
- 단계 링크 클릭 → 해당 상위 빌드 단계 로그 필터 선택과 실제 로그 49건 조회.
- Java 테스트는 native 시간 매핑, 잘못된 시간·미완료 제외, 기간 경계, 다른 단계 ID 비교 차단, 실제 템플릿 렌더링, 보고서 선택, 구획·파이프라인 경계 검증을 포함한다.

## 제한

시간 표본 수를 표시한다. 여러 아키텍처·설정이 섞인 요약을 성능 개선으로 판정하지 않는다. 병렬 단계·하위 작업을 합산하지 않는다. 명세 원문·환경변수의 과거 값은 추정하지 않는다. 현재 설정으로 과거 실행 정보를 덮지 않는다.

보고서가 없는 실행을 테스트 성공으로 표시하지 않는다. Object Storage 보고서는 기존 실행 상세에서 조회하며 이 화면의 자동 비교 대상은 아니다. PMD 렌더링은 기존 판독기를 재사용하지만 이번 실제 비교 대상에는 PMD 보고서가 없었다.

이 기능은 OCI DevOps 빌드 대상이다. Functions 실행·배포 단계의 집계, 이전 기간 추세, 아키텍처별 통계, 설정 원문 차이 및 운영 변경 실패율은 이번 범위에 포함하지 않는다.
