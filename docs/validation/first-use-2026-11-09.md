# 공개 알파 첫 사용 흐름 점검

2026-11-09, 실제 OCI 프로파일과 별도 빈 로컬 데이터 디렉터리에서 Playwright로 확인했습니다. 사람을 대상으로 한 독립 사용성 평가는 아닙니다.

## 변경

- 리소스 화면과 빈 빌드 작업 목록에서 시작 안내로 이동합니다.
- 안내는 소스 → 프로젝트·로그 → 빌드 설정 → 실행·결과 → 선택적 배포 순서로 실제 메뉴에 연결합니다.
- 조회·실행 실패 화면에 전역 메뉴, 오류 코드, 관련 목록·이력 및 권한 안내를 유지합니다.
- 입력 오류 400, 중복·만료 요청 409, 항목 없음 404, 서비스 사용 불가 503으로 구분합니다.

## 확인

- 테스트 196개 통과. 중복 요청의 재실행 방지와 오류 화면의 메뉴 유지 회귀 검증 포함.
- 시작 안내의 내부 연결 화면 모두 HTTP 200.
- 390/768/1440px에서 안내·오류 화면의 가로 넘침 없음.
- HTTP Git 주소 등록 거절 알림, 만료된 OKE 미리보기의 오류 화면과 배포 이력 복귀 확인.
- 공개 db-companion 소스를 로컬 등록하고 새 빌드 작업의 소스 목록에 표시됨을 확인.
- OCI 생성·빌드·배포는 실행하지 않았습니다. 새 OKE/Container 배포·실제 롤백·PVC 보존 검증은 여전히 별도 과제입니다.

재현: 별도 `COMPANION_DATA_DIR`로 앱을 실행한 뒤 `scripts/browser-first-use.cjs`를 사용합니다. `COMPANION_TEST_URL`, `COMPANION_TEST_PROFILE`, `COMPANION_TEST_REGION`, `COMPANION_TEST_COMPARTMENT`(표시 이름), `COMPANION_TEST_LOCAL_WRITE=1`이 필요합니다. 소스 등록은 해당 테스트 디렉터리에 저장됩니다.
