# OKE 서버 도구 안내 검증

2026-11-10. OKE 조회 연결 화면에서 설정된 OCI CLI·kubectl 파일과 실행 권한을 표시한다. 실행 파일 확인은 인증·RBAC 성공을 뜻하지 않는다. kubectl은 기존 실행 어댑터와 동일하게 절대 경로만 인정한다. OCI CLI 이름은 서버 PATH의 절대 경로에서 찾는다.

- Java 테스트 256개 통과. 파일 누락·실행 권한 없음·디렉터리·상대 PATH 제외를 검증했다.
- alpha.8 후보 ZIP을 별도 폴더에 풀고 빈 데이터로 8092에서 실행했다.
- DEFAULT 프로파일, 서울/Joungmin.Ko에서 실제 로그인·클러스터 조회와 kubectl 설정 필요 안내를 브라우저로 확인했다.
- 390·768·1440px에서 가로 넘침이 없었다.
- 검증 스크립트: `scripts/browser-oke-tools.cjs`. 클라우드 리소스를 변경하지 않는다.

패키지 안내는 기존 폴더에서 JAR 교체, `.data`와 `.tools` 보존, OKE 절대 경로의 이동 제한을 명시한다. 이 검증은 새 빌드·배포 실행이나 alpha.8 공개 완료를 의미하지 않는다.
