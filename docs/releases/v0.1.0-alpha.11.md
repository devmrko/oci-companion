# v0.1.0-alpha.11

- OKE 사설 접속 준비 도움말: VCN 경로·기존 SSH 서버·앱 실행 예제.
- 실제 사설 API에서 namespace·Deployment·연결 저장·준비 완료·Pod 로그 조회 검증.
- 터널 중단 시 조회 불가, 복원 시 준비 완료 확인. 공인 API 우회나 TLS 검증 해제 없음.

Java 259개와 연결·로그 도움말의 390·768·1440px 검증이 통과했습니다. JAR 교체 후 저장된 사설 연결이 유지됐습니다. 기존 alpha.10 기능과 설정 형식을 유지합니다.

JDK 21 이상, OCI API 키 프로파일이 필요합니다. ZIP을 풀고 `./run.sh`로 실행하세요. 업데이트는 종료 후 JAR 교체, `.data`·`.tools` 보존입니다.

SSH/SOCKS5 경로를 검증했으며 관리형 Bastion·VPN·전용회선 구축 검증은 아닙니다. 외부 신규 사용자 사용성 검증은 별도입니다. 개인 로컬 실행용 알파입니다.
