# OCI Companion v0.1.0-alpha.7

- 배포 재시도·새로고침에서 원본 빌드 선택 유지, 산출물 일치 재검증.
- 배포 전 점검표: 확인한 항목과 미확인 항목 구분.
- 실제 OCIR digest 조회, 명확한 부재·삭제 이미지 실행 차단.
- OCI 프로파일로 사설 이미지 플랫폼 조회, 명세의 x86/ARM 불일치 차단. 별도 Docker·비밀번호 불필요.
- Container Instances 사설 이미지 권한·동적 그룹 한도 해결 안내.

JDK 21 이상과 OCI API 키 프로파일이 필요합니다. ZIP을 풀고 `./run.sh`로 시작합니다. 업데이트 전 앱을 종료하고 기존 `.data`를 보존하세요.

실제 노드 라벨·스케줄링·네트워크·런타임 pull 권한까지 자동 검증하지는 않습니다. Container Instances 사설 이미지 정상 실행은 동적 그룹 한도로 미완료입니다. [지원 범위](alpha-readiness.md)를 확인하세요.

검증: Java 230개, 독립 ZIP의 실제 OCI 화면 10개·사설 이미지 아키텍처 조회, alpha.6 데이터 복사본의 소스·리전·구획 유지, 390/768/1440px 확인. [설치·업데이트 기록](../validation/alpha7-package-2026-11-10.md).
