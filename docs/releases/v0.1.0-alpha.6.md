# OCI Companion v0.1.0-alpha.6

- 빌드 로그 조회 실패 시 이전 로그·마지막 성공 시각 표시, 자동 갱신 중지.
- 로그 검색 표시 건수와 전체 조회 건수 구분.
- 보고서 목록·본문 조회 중 선택 변경 시 이전 응답 제외.
- 보고서 선택 전 보기 비활성화, 조회 실패 후 재시도 안내.
- 별도 실행 폴더를 사용할 수 있도록 빌드 화면 검증 스크립트 개선.

JDK 21 이상과 OCI API 키 프로파일이 필요합니다. 실행 ZIP의 `run.sh`로 시작합니다. 업데이트 전 기존 `.data`를 보존하세요.

[지원 범위와 제한](alpha-readiness.md)을 확인하세요. 사설 OCIR Container Instances, 일반 VM 수동 파일시스템 확장, 예약 시각의 자동 백업 생성은 이번 릴리스의 실검증 범위가 아닙니다.

[독립 ZIP · 소스→빌드→VM 배포 검증](../validation/alpha6-flow-2026-11-10.md)

빈 로컬 설정의 ZIP에서 실제 빌드→산출물 전달→VM HTTP 응답→기존 v1 복구를 확인했습니다. 주요 화면 10개, 390/768/1440px, Java 테스트 219개 통과. 검증 VM은 중지 상태로 복원했고 임시 IAM 정책을 삭제했습니다.
