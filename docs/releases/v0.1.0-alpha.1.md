# v0.1.0-alpha.1

OCI 프로파일로 연결하는 로컬 CI/CD 관리 도구의 공개 알파입니다. JDK 21 이상, macOS/Linux를 대상으로 합니다.

## 시작

1. 릴리스의 ZIP과 SHA-256 파일을 같은 폴더에 내려받습니다.
2. `shasum -a 256 -c oci-companion-0.1.0-alpha.1.zip.sha256`으로 확인합니다.
3. ZIP을 풀고 해당 폴더에서 `./run.sh`를 실행합니다.
4. http://127.0.0.1:8091 에서 기존 OCI 프로파일·리전·구획을 선택합니다.

GitHub CLI·별도 DB·비공개 저장소 접근은 필요하지 않습니다. 소스 빌드는 `./scripts/build.sh`를 사용합니다.

## 범위

- 프로파일 기반 리소스·소스 관리, OCI 빌드·산출물·로그 조회.
- 준비된 VM 배포와 기존 OKE 배포 상태 조회.
- 새 OKE 구성·이전 버전 복구·Container 운영은 실험 기능입니다.

신규 파이프라인과 Container의 리소스 주체 권한을 별도로 준비해야 합니다. 새 OKE/Container 배포 성공, 실제 롤백, PVC 데이터 유지·백업 복원은 아직 검증되지 않았습니다. 공유 서버·외부 공개·운영 무중단 배포 용도로 사용하지 마세요. 자세한 내용은 [지원 범위](alpha-readiness.md)를 확인하세요.

## 검증

- 로컬 테스트 196개 통과.
- 비공개 Foundation 의존성 제거. 실행 JAR에 해당 라이브러리가 없음을 확인.
- 별도 폴더·빈 데이터·개발 환경변수 없는 실행 ZIP에서 실제 OCI 로그인과 5개 화면 조회, 390/768/1440px 레이아웃 확인.
- 전체 Git 이력과 GitHub 이슈·댓글의 비밀정보 검사 수행. 합성 Vault 참조 문자열 5건만 정확한 위치로 제외. 실제 비밀값 탐지 없음. 이는 모든 보안 취약점이 없다는 보장이 아닙니다.

업데이트 전 앱을 종료하고 `.data/catalog`를 보존하세요. 이슈에는 키·토큰·프로파일 원문·민감한 로그를 첨부하지 마세요.
