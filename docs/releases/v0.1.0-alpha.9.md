# v0.1.0-alpha.9

- 새 프로젝트의 소스·빌드 명세 업로드와 OCI 권한 문제 확인 도움말 추가.
- 프로젝트 조회 실패와 정상 빈 목록 구분.
- 알림·Registry 목록 조회 실패 시 생성 폼 숨김. CLI 도움말 유지.

검증: Java 테스트 259개, 독립 ZIP의 실제 OCI 화면 10개와 변경 화면 3개, 390·768·1440px. alpha.8에서 JAR 교체 시 설정 JSON 319개와 소스·범위·등록 앱·실제 OKE 조회 연결이 유지됐습니다. 이번 패키지 검증에서 빌드·배포를 다시 실행한 것은 아닙니다.

JDK 21 이상과 OCI API 키 프로파일이 필요합니다. ZIP을 풀고 `./run.sh`로 실행합니다. 업데이트는 앱 종료 후 기존 설치 폴더의 JAR를 교체하고 `.data`·`.tools`를 보존하세요. OKE 연결에 절대 경로가 저장되므로 폴더를 옮기면 연결을 다시 저장해야 합니다.

사설 이미지의 Container Instances 실행, OKE 사설 API·실제 RBAC 제한, 외부 신규 사용자 사용성 검증은 남아 있습니다. 개인 로컬 실행용 알파이며 공유 서버·인터넷 공개는 지원하지 않습니다.
