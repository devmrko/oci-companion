# v0.1.0-alpha.3

백업·복구 메뉴를 추가했습니다. OCI 블록 볼륨·백업 조회, 전체/증분 백업 생성, 백업에서 별도 볼륨 복원을 지원합니다. 확인 화면과 일회용 요청으로 프로파일·리전·구획 변경 및 중복 실행을 검사합니다. VM 사양 오류에서도 메뉴와 돌아가기 경로를 유지합니다.

테스트 205개 통과. 실제 화면에서 전체 백업·새 볼륨 복원·50→51GB 확장을 실행했습니다. 복원 파일의 SHA-256 일치와 OKE CSI의 파일시스템 확장 후 파일 유지를 확인했습니다.

부트 볼륨·정기 정책·보존 잠금은 OCI 콘솔에서 관리합니다. 증분 백업의 실제 실행, DB 일관성 복원, 일반 VM의 수동 OS 확장, 사설 Container 인증의 실제 실행은 아직 검증하지 않았습니다. [지원 범위](https://github.com/devmrko/oci-companion/blob/main/docs/releases/alpha-readiness.md)를 확인하세요.

JDK 21 이상과 `~/.oci/config`의 API 키 프로파일이 필요합니다. ZIP과 체크섬을 내려받아 `shasum -a 256 -c oci-companion-0.1.0-alpha.3.zip.sha256`으로 확인하고 압축을 푼 폴더에서 `./run.sh`를 실행하세요. 기본 주소는 http://127.0.0.1:8091 입니다.

업데이트 전 앱을 종료하고 `.data/catalog`를 보존하세요. 이전 알파 배포본은 유지합니다.
