# Public Alpha 지원 범위

2026-11-09. 개인 컴퓨터에서 OCI API 키 프로파일로 실행하는 초기 버전입니다. macOS/Linux·JDK 21 이상을 대상으로 합니다. 공유 서버·외부 네트워크 공개·운영 무중단 배포는 지원 범위가 아닙니다.

## 검증한 흐름

- 프로파일 연결, 리전·구획 선택, 소스 등록, 실제 OCI 리소스 조회.
- OCI 빌드 실행·이력·로그·산출물 전달. 언어별 범위는 예제와 검증 문서를 참고하세요.
- 준비된 VM 환경의 배포·로그와 CPU·메모리 변경·복원.
- OKE 새 구성 실행·상태·로그·v2 → v1 복구. [실검증](../validation/oke-live-2026-11-09.md).
- Container Instances 공개 이미지 생성·HTTP 상태·로그·중지·시작·재시작·삭제. [실검증](../validation/container-live-2026-11-09.md).
- 별도 폴더와 빈 데이터에서 실행 ZIP 기동·프로파일 연결·조회.

단위 테스트 통과, API 요청 접수, 실제 앱 정상 응답을 구분합니다. 개발자의 계정에서 확인한 결과이며 모든 테넌시 권한 조합을 보장하지 않습니다.

## 실험 기능·알려진 제한

| 기능 | 구현·검증 상태 |
| --- | --- |
| 새 OKE 구성 | 이미지·사양·YAML·OCI 저장·실제 배포 성공 검증. 실행 주체 IAM과 이미지 인증은 별도 준비 |
| 이전 배포 복구 | 화면에서 실제 v2 → v1 복구·리소스 로그 확인. 데이터베이스·파일 데이터의 복원은 별개 |
| Container Instances | 공개 digest 이미지의 생성·정상 실행·운영·삭제 검증. 사설 OCIR 및 외부 Vault 인증 이미지의 실행은 미검증 |
| 영구 스토리지 | 기존 PVC·fsGroup 설정, 비루트 파일 쓰기·Pod 교체 후 데이터 유지 검증. 백업·복원은 미검증 |
| VM 볼륨 확장 | 미리보기·SDK 연동 구현. 실제 확장·OS 파일시스템 작업 미검증 |
| 신규 사용자 사용성 | 자동 브라우저 검증 수행. 외부 신규 사용자의 전체 흐름 검증은 남음 |

실험 기능은 전용 검증 환경에서 사용하세요. `예정` 메뉴는 구현되지 않았습니다. 생성·빌드·실행에는 OCI 비용이 발생할 수 있습니다.

## 설치·업데이트

릴리스 ZIP: JDK 21 이상과 `~/.oci/config`의 API 키 프로파일을 준비하고 압축을 푼 폴더에서 `./run.sh`를 실행합니다. 기본 주소는 http://127.0.0.1:8091 입니다. GitHub CLI·비공개 Foundation 저장소 접근은 필요하지 않습니다.

소스: `./scripts/build.sh` → `./scripts/run.sh`. 공개 Maven 의존성을 내려받습니다.

로컬 설정·참조·캐시는 `.data/catalog`에 있습니다. 업데이트 전 앱을 종료하고 이 폴더를 보존하세요. 새 버전에 `.data/catalog`를 옮기며, 문제가 있으면 이전 실행 ZIP과 보존한 데이터를 함께 사용하세요. 이는 OCI 리소스의 롤백이 아닙니다. 여러 프로세스가 같은 데이터 폴더를 동시에 사용하면 안 됩니다.

## 권한·실패 처리

앱은 프로파일 권한으로 SDK를 호출하며 IAM 권한을 자동 확대하지 않습니다. 화면 도움말의 OCI 콘솔 위치에서 필요한 프로젝트·구획 범위로 관리자가 설정해야 합니다. 사용자 권한과 DevOps·노드·Container 리소스 주체의 권한은 별개입니다.

응답이 불명확한 생성·실행 요청은 이력과 OCI 상태를 확인한 후 재실행하세요. 권한 오류를 해결하려고 무조건 tenancy 전체 관리 권한을 부여하지 마세요.

문제 신고에는 재현 단계·버전·오류 코드를 포함하세요. 키·토큰·프로파일 원문·`.env`·개인 캐시·민감한 빌드 로그는 첨부하지 마세요.
