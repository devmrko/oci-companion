# 제한적 알파 기준

2026-11-09. 대상은 OCI 계정과 API 키 프로파일을 가진 소수의 개발자다. 로컬에서 실행하며 사용자 프로파일의 권한으로 작업한다. 이 문서는 공개 배포 완료를 뜻하지 않는다.

## 제공 범위

소스 등록 → OCI 빌드 → 산출물 조회 → 검증된 VM 배포·로그를 우선 제공한다. 기존 OKE 배포의 상태·로그 조회도 제공한다. 새 OKE 구성·이전 버전 복구·Container 운영은 실제 검증 범위를 표시한 실험 기능으로 취급한다. 예정 메뉴를 구현 완료로 소개하지 않는다.

## 공개 전에 통과해야 할 항목

- 개발자의 `.env`나 `.tools` 설정 없이 배포 JAR로 시작하고 본인의 OCI 프로파일을 연결한다.
- 소스 등록부터 성공 빌드·VM 배포·로그까지 신규 사용자 한 명 이상이 화면에서 완료한다.
- 권한 부족·빈 목록·잘못된 설정·OCI 응답 실패가 메뉴를 유지한 화면에 표시된다. 재시도로 중복 리소스를 만들지 않는다.
- 새 OKE 배포와 이전 성공 버전 복구를 전용 Namespace에서 검증한다. Pod 준비 상태와 HTTP 응답을 확인한다.
- Container 사설 이미지 인증을 해결하고 시작·중지·재시작·삭제를 전용 인스턴스에서 검증한다.
- PVC·볼륨·백업은 연결 설정, 실제 데이터 유지, 복원 시험을 구분해 표시한다.
- JAR·샘플·문서에 API 키·환경변수 값·실제 사용자 설정·검증 산출물을 포함하지 않는다.

## 배포물·설치

소스 빌드는 현재 GitHub CLI와 Foundation 저장소 접근이 필요하다. 외부 알파 사용자에게 이 권한을 요구하지 않도록 빌드된 실행 JAR을 제공해야 한다. 런타임은 JDK 21과 OCI API 키 프로파일이 필요하다. 공개 릴리스 업로드와 신규 사용자 검증은 아직 수행하지 않았다.

## 실패 처리

권한을 앱이 자동 확대하지 않는다. OCI 콘솔 위치·필요 권한·선택한 리전과 구획을 안내한다. 응답이 불명확한 생성·실행 요청은 이력 조회 후 판단한다. 단위 테스트 통과, API 요청 접수, 실제 앱 정상 응답을 각각 기록한다.
