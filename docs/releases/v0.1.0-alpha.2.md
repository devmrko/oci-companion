# v0.1.0-alpha.2

OKE 실행 권한 안내, 비루트 앱의 PVC 접근 그룹, Container 외부 Registry 설정을 보완했습니다.

- 첫 사용 안내와 오류 후 돌아가기 경로를 추가했습니다.
- OKE 배포 화면에서 선택한 파이프라인·클러스터의 IAM 예제를 확인할 수 있습니다.
- PVC 연결 시 선택 항목인 볼륨 접근 그룹을 Kubernetes fsGroup으로 전달합니다.
- Container Instances에서 공개 digest 이미지와 외부 Registry의 Vault 인증 참조를 설정할 수 있습니다. 사설 OCIR 인증과 외부 Registry 인증은 구분합니다.

## 검증

Java 테스트 199개와 실제 OCI 연결 화면 5곳의 390/768/1440px 검증을 통과했습니다. 화면에서 OKE v1→v2→v1 복구, Container 생성·HTTP HEALTHY·로그·중지·시작·재시작·삭제를 확인했습니다. OKE 사설 OCIR 이미지의 비루트 PVC 쓰기와 Pod 교체 후 파일 유지도 검증했습니다.

사설 OCIR Container Instances와 외부 Vault 인증 이미지의 실실행, 데이터 백업·복원, VM 볼륨 확장·OS 파일시스템 작업은 아직 검증하지 않았습니다. 공유 서버·외부 공개·운영 무중단 배포용이 아닙니다. [지원 범위](https://github.com/devmrko/oci-companion/blob/main/docs/releases/alpha-readiness.md)를 확인하세요.

## 설치

JDK 21 이상과 `~/.oci/config` API 키 프로파일이 필요합니다. ZIP과 SHA-256 파일을 내려받아 `shasum -a 256 -c oci-companion-0.1.0-alpha.2.zip.sha256`으로 확인하고, 압축을 푼 폴더에서 `./run.sh`를 실행하세요. 기본 주소는 http://127.0.0.1:8091 입니다.

업데이트 전 앱을 종료하고 `.data/catalog`를 보존하세요. 기존 alpha.1 ZIP은 그대로 남습니다. 키·토큰·프로파일 원문·민감한 로그는 이슈에 첨부하지 마세요.
