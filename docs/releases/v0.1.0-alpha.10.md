# v0.1.0-alpha.10

- Container Instances 사설 OCIR 읽기 policy 준비·단일 인스턴스 제한 도움말.
- OKE 연결·로그 화면에 OCI IAM과 namespace Role/RoleBinding 예제.
- 실제 임시 계정의 OKE 조회 거부·허용·로그 권한 회수 검증.

검증: Java 259개, 독립 ZIP 주요 화면 10개와 프로젝트·알림·Registry, 390·768·1440px. alpha.9에서 JAR 교체 후 설정 JSON 319개·소스·범위·등록 앱·실제 OKE 연결을 유지했습니다. 사설 OCIR 이미지는 조건부 policy로 Container Instances에서 HTTP 정상·로그를 확인했습니다.

JDK 21 이상과 OCI API 키 프로파일이 필요합니다. ZIP을 풀고 `./run.sh`로 실행하세요. 업데이트 전 종료 후 기존 설치 폴더의 JAR를 교체하고 `.data`·`.tools`를 보존하세요.

OKE 사설 API 성공은 미검증입니다. 앱 서버에 경로가 없으며 Bastion 생성 한도와 대체 VM 생성 404로 추가 검증을 완료하지 못했습니다. 외부 신규 사용자 사용성 검증도 남습니다. 개인 로컬 실행용 알파이며 공유 서버·인터넷 공개는 지원하지 않습니다.
