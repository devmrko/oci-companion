# 파이프라인 실행 전 IAM 점검

빌드 담당자는 실행 전에 리소스 주체의 권한을 확인하고, 부족한 권한만 새 정책으로 추가할 수 있어야 한다. 기존 사용자 그룹 안내와 별개로 빌드·배포 파이프라인 동적 그룹을 확인한다.

`PipelineIam` 포트는 조회와 생성 계획을 제공한다. OCI 어댑터는 기존 프로필 인증·범위 검증을 재사용하며 테넌시 홈 리전에서 동적 그룹과 현재 구획부터 루트까지 정책을 읽는다. 명확히 판독 가능한 무조건 정책만 충족으로 인정한다. 조건식이나 조회 실패는 권한 없음으로 확정하지 않는다.

화면에서 조회 → 부족한 문장·동적 그룹 규칙·범위 미리보기 → 확인 → 새 리소스 생성 순서로 진행한다. 미리보기는 인증 주체·리전·구획·파이프라인에 묶고 일회성으로 소비한다. 기존 정책과 동적 그룹은 수정하지 않는다. 생성 후 수 분의 전파 대기를 안내한다. 루트 범위는 별도로 경고한다.

복사 명령은 실제 범위를 포함하되 실행 결과와 오류에서는 OCID를 가린다. OCI 오류의 서비스 코드와 비밀값을 제거한 메시지를 보여 준다. 복잡한 IAM 조건을 완전한 권한 평가기로 해석하지 않는다.

검증: 동적 그룹 조건·상위 권한·다른 구획·조건부 정책·조회 실패·미리보기 범위 변경·중복 실행과 실패 단계 표시를 테스트한다. 실제 OCI 검증 결과는 backlog 문서에 별도로 기록한다.
