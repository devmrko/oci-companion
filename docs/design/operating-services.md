# 등록 서비스에서 빌드와 배포 이어가기

운영자가 서비스별 연결 정보를 반복 입력하지 않고 커밋을 골라 ARM 빌드·OCIR push·OKE 재배포·상태 확인을 진행하기 위한 기능입니다. 기존 `ArmBuilds`, `OkeDeploymentSetup`, `DeploymentOperations`, `OkeWorkloadConnections`, `SourceVersions`를 재사용합니다.

등록에는 소스 저장소·브랜치, ARM 빌더, 이미지 저장소, OKE 환경·조회 연결, 저장한 배포 구성, 단일 OKE 파이프라인, NodePort와 워커 보안 목록의 읽기 전용 규칙 스냅샷을 포함합니다. 인증 주체·리전·구획별 기존 원자적 로컬 저장소에 저장합니다. Secret 이름만 참조하며 비밀값은 저장하지 않습니다.

커밋을 선택하면 등록된 명령·대상으로 빌드 미리보기를 만듭니다. 승인 후 기존 ARM 실행기를 호출하고 결과 digest를 OCIR에서 다시 찾습니다. 배포 미리보기에서 현재 Deployment의 설정을 보존하고 이미지 digest만 바꿉니다. 별도 확인 후 등록 파이프라인의 단일 인라인 명세를 etag로 갱신하고 공통 DeploymentOperations의 prepare/execute를 호출합니다. Service·보안 규칙·IAM·Secret은 이 흐름에서 변경하지 않습니다.

계획은 인증 주체·선택 범위·브라우저 세션·10분 만료·일회용 티켓에 묶습니다. 등록 설정이 바뀌거나 빌드가 실패하면 배포하지 않습니다. 불확실한 실행 결과는 자동 재시도하지 않고 원본 실행 화면으로 연결합니다. 배포 실행 ID와 빌드 실행 ID를 별도로 유지합니다. 신규 이미지의 아키텍처·레지스트리·현재 Deployment 구성을 실행 전에 재확인합니다.

첫 운영 등록 대상은 sustena-c이며 기존 운영 이미지 변경 없이 등록합니다. 전체 새 이미지 전달 검증은 별도 sustena-verify 서비스에서 수행하고 검증 클라우드 자원은 정리합니다.
