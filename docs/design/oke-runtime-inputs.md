# OKE 앱 실행 설정과 재배포

배포 담당자는 지갑 파일·임시 디렉터리·실행 권한·HTTP 프로브를 화면에서 지정하고, 다시 구성할 때 저장한 설정을 불러올 수 있다. Kubernetes Deployment의 표준 필드로 렌더링해 OCI에 저장된 명세 자체에도 설정을 보존한다.

기존 입력 레코드와 YAML 생성기를 확장한다. 파일 볼륨은 `종류 이름 마운트경로 읽기전용` 형식이며 Secret·ConfigMap 이름만 참조한다. emptyDir는 경로 목록이다. 중복 마운트·잘못된 경로·헤더 제어문자를 거부하고 모든 파일 참조를 기존 Namespace 리소스 점검에 포함한다.

Pod·컨테이너 runAsNonRoot, 읽기 전용 루트 파일시스템, capabilities drop ALL, 서비스 계정 토큰 자동 마운트, 프로브 공통 HTTP 헤더와 timeoutSeconds를 별도로 지정한다. 인증 헤더·쿠키 같은 비밀값은 입력하지 않는다.

공용 Namespace에서는 Namespace 객체를 생성하지 않도록 선택할 수 있다. default Namespace는 객체를 항상 생략하며 Kubernetes 시스템 Namespace는 계속 금지한다. 성공적으로 구성을 생성하면 인증 주체·리전·구획·환경에 묶인 입력을 로컬에 저장한다. 이후 해당 환경 구성에서 다시 불러오되 새 리소스 생성에는 기존 미리보기·검증을 다시 거친다.

기존 CLI로 수정한 운영 Deployment에서 설정을 자동 추출하는 기능은 이 입력 저장과 별개다. 실제 2/2 Ready와 재배포 결과는 검증 배포에서 따로 확인한다.
