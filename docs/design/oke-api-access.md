# 사설 OKE API 접속

같은 클러스터의 상태·로그와 배포 참조 조회가 같은 접속 설정을 사용하도록 한다. 사용자는 별도 접속 설정 화면에서 HTTPS server·TLS server name을 재정의하거나 SSH 점프 호스트·사용자·키 경로를 지정한다. OCI 네트워크와 IAM은 이 설정으로 변경하지 않는다.

설정은 인증 주체·리전·구획·클러스터별로 기존 로컬 설정 저장소에 보관한다. kubectl 공통 실행기에서 설정을 적용하므로 조회 연결과 배포 구성에 함께 반영된다. SSH는 인자 배열로 실행하고 호스트 키 검증을 끄지 않는다. loopback 포트만 열고, 설정 변경·사용자 연결 해제·앱 종료 시 소유한 터널 프로세스를 닫는다.

OCI 토큰은 인증 주체·리전·클러스터별 메모리 캐시에서 만료 전에 재사용한다. 각 kubectl 요청에 0600 임시 kubeconfig를 만들고 요청 종료 시 삭제한다. 원본 kubeconfig의 실행 명령은 유지하여 재시작·만료 후 갱신할 수 있다. 토큰과 SSH 키 내용은 로그·화면·문서에 노출하지 않는다.

kubectl 요청 제한을 30초, 전체 프로세스 제한을 45초로 늘린다. 참조 조회 버튼은 실패 후 다시 실행할 수 있다. 실제 터널·상태·로그 성공은 검증 환경에서 별도로 확인한다.
