# 에이전트 실행 조회 연결

2026-11-05. 서울 Launchpad 예제의 health·요청 추적을 Companion에서 확인합니다. 기존 OCI 프로파일 연결과 리전·구획 선택을 그대로 사용합니다.

설정 파일은 연결 프로파일·테넌시·사용자·리전·구획, 표시 이름, 로컬 SSH 터널 URL, 토큰 파일 경로를 가집니다. 이 값들은 로컬 운영자가 설정하며 화면에서 임의 URL·명령을 받지 않습니다. 일치하는 연결·범위에서만 외부 조회를 수행합니다. 첫 버전은 http://127.0.0.1의 명시 포트만 허용하고 리다이렉트를 따르지 않습니다. 토큰은 파일에서 읽고 화면·오류·로그에 노출하지 않습니다.

포트 AgentMonitoring → HTTP 어댑터 → 웹 페이지로 책임을 나눕니다. 조회 데이터는 health 버전, 요청 ID, 결과, 모델·리전·토큰·지연, 도구·실패 단계만 표시합니다. 프롬프트·대화·접수 원문은 표시하지 않습니다. 원격 장애와 미설정·범위 불일치를 성공으로 바꾸지 않습니다. 응답은 2MB, 표시 기록은 최대 100건으로 제한하고 연결/요청 제한시간을 적용합니다.

이 화면은 설정된 합성 앱 인증 주체의 실행을 조회하는 첫 연결입니다. 다중 고객 관리자 권한·전체 사용자 통합 관측·APM·비용 추정은 아직 제공하지 않습니다. 테스트는 범위 불일치 시 네트워크 미호출, 토큰 전달, 리다이렉트 금지, 응답 크기, 오류 비노출과 민감 필드 제외를 확인합니다.

검증: 전체 103개 테스트 통과. 서울의 실제 0.2.0 앱을 SSH 터널로 조회해 UP, 모델 토큰·리전, search/propose/approve 기록을 화면에서 확인했습니다. 요청 헤더 대기와 본문 읽기에 각각 8초 제한을 적용합니다.
