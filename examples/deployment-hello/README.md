# VM 배포 검증 예제

표준 라이브러리만 사용하는 HTTP 예제입니다. `app.py`와 `version.txt`를 함께 tar.gz로 묶고 불변 Generic Artifact 저장소에 버전별로 등록합니다. `/hello`는 메시지와 버전을 반환합니다. 로컬 VM 내부 127.0.0.1:8080에만 바인딩합니다.

OCI Companion에서 환경·배포본·설치/시작/상태 확인 명령·환경변수를 입력합니다. 예제 명령은 `scripts/browser-vm-live.cjs`에 있으며 앱 구현에는 이 예제의 경로나 명령이 하드코딩되지 않습니다.

검증 경로는 `/var/tmp/companion-hello`입니다. 전용 계정에서 해당 디렉터리를 준비하고, 기존 앱의 경로나 포트를 사용하지 않는지 확인합니다. `RELEASE_VERSION=v1` 또는 `v2`를 배포 변수로 지정합니다. 예제의 프로세스 실행 방식은 배포·복구 검증용입니다. 운영 서비스에는 systemd 등 환경에 맞는 서비스 관리 방식을 사용하세요.

v1 배포 → v2 배포 → v1 파이프라인 재실행 순서로 이전 배포본 복구를 확인합니다. 데이터베이스 데이터나 운영 데이터 복구는 포함하지 않습니다.
